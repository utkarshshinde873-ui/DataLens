# 📊 DataLens — Data Visualization & Storytelling Dashboard

### Turn Raw Data into Meaningful Insights 🚀

DataLens is an interactive data visualization and storytelling web application that transforms datasets into meaningful charts, statistical insights, and easy-to-understand stories.

Users can explore student performance data, visualize relationships between variables, identify patterns, and understand their data through an interactive dashboard.

---

## ✨ Features

- 📈 **Interactive Visualizations** — Generate bar charts, histograms, scatter plots, and donut charts.
- 📊 **Statistical Insights** — Analyze averages, distributions, and relationships between numerical variables.
- 📖 **Data Storytelling** — Convert dataset findings into simple, understandable paragraphs.
- 📁 **CSV Upload** — Upload your own CSV dataset for analysis.
- 📥 **CSV Export** — Export data for further analysis.
- 🔍 **Data Explorer** — Search, browse, and inspect dataset records.
- 🎛️ **Independent Chart Controls** — Customize individual charts without affecting the others.
- 📌 **Dashboard KPIs** — View key dataset metrics, including row counts, fields, and averages.
- 🎓 **Student Performance Dataset** — Explore academic performance and student habits using sample data.
- 🌙 **Modern Dashboard UI** — Clean interface with a dark-text, light-background design and colorful visualizations.

## 📂 Dataset

DataLens includes a sample student performance dataset containing fields such as:

| Column | Description |
|---|---|
| Student | Student identifier |
| StudyHours | Hours spent studying |
| Attendance | Attendance percentage |
| ScreenTime | Daily screen time |
| CGPA | Cumulative Grade Point Average |
| AssignmentCompletion | Assignment completion percentage |
| SleepHours | Hours of sleep |

The dataset can be used to explore patterns in academic performance, study habits, attendance, screen time, and sleep.

Users can also upload their own CSV files to explore different datasets.

---

## 📊 Visualizations

DataLens supports multiple visualization types:

- **Bar Chart:** Compare values across categories.
- **Histogram:** Understand the distribution of numerical values.
- **Scatter Plot:** Explore relationships between two numerical variables.
- **Donut Chart:** Understand proportions and category distributions.

Each chart has independent controls, allowing users to explore different aspects of their data.

---

## 🧠 Data Storytelling

The Data Story feature presents dataset findings in simple paragraphs instead of displaying charts alone.

It helps users understand:

- Important patterns in the dataset.
- Relationships between study habits and academic performance.
- Differences in student performance.
- Potential areas for further investigation.
- Key takeaways from the analysis.

The observations depend on the uploaded dataset and should be interpreted as exploratory findings rather than proof of cause and effect.
